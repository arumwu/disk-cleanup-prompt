# Disk Cleanup Prompt

把「幫我清硬碟」變成「先看清楚，再自己決定」。

這是一組給本機 AI 代理使用的提示詞：唯讀盤點開發工作留下的資料夾，產生本機空間地圖，再讓使用者勾選、下載清理腳本。**代理不執行清理。**

## 三步開始

1. 開啟能在你的電腦上執行命令、寫入本機檔案的 AI 代理。先使用你平常的權限，不要為這個任務另外開啟完整磁碟存取或管理員權限。
2. 複製[完整提示詞](prompts/disk-cleanup.zh-TW.md)，貼給代理。讓它依實際作業系統掃描、產生報告並驗證。
3. 開啟代理交付的 **`index.html`**。先看路徑、大小與刪除影響；想清理時再勾選、下載腳本，於終端機執行。輸入 `yes` 才能開始。

一般只有網頁聊天、沒有本機工具權限的 AI，無法直接盤點你的電腦。這個倉庫也不會替 AI 取得額外權限。

## 會得到什麼

- 左側矩形樹狀圖（treemap）：矩形面積對應佔用空間。
- 右側兩組清單：「可以直接清」與「先讓我看過」，每項都有路徑、大小、刪除影響。
- 作品資料夾只標示，不列入清理建議。
- 對話紀錄依最後變動時間分成超過／最近 14 天；最近的標示「不建議刪」，memory 排除。
- Git worktree 必須通過四項檢查，才可能建議移除。
- 家目錄外的暫存區也會量大小，但只有符合保留天數與使用狀態的項目能進入清理建議。
- `sizes.csv` 追加歷次容量；下一次掃描標出增加的項目。

「可以直接清」表示已確認可重建，**不是已授權刪除，也不是保證可釋放的容量**。有程式使用、用途不明或查核不完整的項目，可能只能查看，不能勾選。

## 清理的控制權在你手上

報告預設全部不勾選。優先使用作用範圍能對應勾選項目的工具清理指令；沒有適用指令時，腳本預設印出「略過」。只有使用者另行打開選項，才允許一般刪除命令。

Unix 類系統的一般刪除可能使用 `rm -rf`；Windows 必須採對應方式。這個選項也不能繞過作品、memory、近期對話、worktree 查核或程序使用中的保護。

Git worktree 只能使用 `git worktree remove`，不能以 `rm -rf` 或 `--force` 代替。被 `.gitignore` 忽略、只存在 worktree 裡的輸出檔，也可能隨移除消失。

## 支援範圍與驗證界線

| 項目 | 狀態 |
| --- | --- |
| 繁體中文提示詞與使用說明 | 本倉庫提供 |
| macOS | 曾依此需求產出本機報告並驗證互動；不是所有版本與工具的相容性保證 |
| Windows／Linux | 提示詞要求調整路徑、權限與指令；本倉庫未實測掃描或清理 |
| 示範頁 | 靜態虛構資料；可離線開啟，不讀取你的磁碟 |
| 自動掃描器／跨平台清理程式 | 本倉庫不提供；由你的代理依環境實作與查核 |
| 自動刪除 | 不提供 |

這是**提示詞與使用流程**的公開分享，不是已通過所有環境驗證的清理工具。AI 可能判斷錯誤，請檢查它交付的報告、清理範圍及腳本。

## 分享時保護自己的資料

可以分享本倉庫與提示詞。**不要直接上傳你自己產生的報告、`sizes.csv`、掃描 JSON、清理腳本或真實截圖**：它們可能透露帳號名稱、專案名稱、完整路徑與工具使用情況。即使沒有讀取檔案內容，中繼資料仍可能敏感；使用雲端 AI 時，也應考慮其資料處理方式。

歡迎透過 Issues 回報不明確的規則、作業系統差異或改良建議。請使用虛構路徑與資料，不要附私人掃描結果。
