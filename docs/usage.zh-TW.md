# 使用說明

## 開始前

需要一個已能在你的電腦上使用命令列、存取檔案中繼資料、產生本機檔案的 AI 代理。提示詞不會替它取得權限。若使用一般網頁聊天而沒有本機工具，AI 只能解釋或寫程式，不能聲稱已掃描你的電腦。

不必先安裝這個倉庫。可以直接開啟 [`prompts/disk-cleanup.zh-TW.md`](../prompts/disk-cleanup.zh-TW.md)，複製全文，貼給你使用的代理。

這項任務會在家目錄的 `disk-report` 建立報告與歷史紀錄。來源只准唯讀；輸出報告需要寫入權限。若已有同名檔案，代理應先確認是否為自己的報告，不可盲目覆蓋。

## 第一次執行

1. 把完整提示詞交給代理。讓它確認 OS、家目錄、允許掃描的位置與可用工具。
2. 等待它產生並驗證 `index.html`。有權限風險或外接位置就跳過，不要為了補齊容量額外開權限。
3. 從交付連結開啟 `index.html`。先看掃描範圍與時間，再看最大的幾個矩形。

掃描可能需要一些時間，取決於檔案數量、磁碟與可用工具。沒有完整掃描的區域應列出原因，不該反覆要求權限。

## 怎麼看報告

| 畫面 | 意思 |
| --- | --- |
| 可以直接清 | 已確認可重建；仍須由你勾選並執行下載腳本 |
| 先讓我看過 | 對話、模型、Docker 或不確定的資料；先確認影響 |
| 僅供查看／不建議刪 | 不符合清理條件，不應能勾選 |
| 作品註記 | 你的作品或輸出，只顯示容量 |
| 預設略過 | 沒有能限定範圍的工具清除指令，一般刪除選項尚未開啟 |
| 比上次增加 | 與前次 `sizes.csv` 同一項目比較的差額 |

第一次沒有比較基準是正常的。某個資料夾很大，也不代表刪除後就能拿回同樣大小：共享區塊、壓縮、正在使用的檔案、工具自己的保留策略，都可能影響結果。

對話的 14 天採最後變動時間，不一定等於建立日期。舊對話只要最近又有變動，就可能落入最近 14 天。無法不讀內容就拆開的資料庫應完整保留。

## 下載與執行腳本

先確認每個勾選項目的路徑與刪除影響。一般刪除的額外選項預設關閉；它不是「全部清光」按鈕，也不能繞過保留規則。

按下載按鈕取得腳本，開啟檔案檢查內容。不要把不理解或與勾選範圍不符的指令直接執行。

macOS／Linux：如果代理交付的是 Bash 腳本，可以在終端機先打 `bash `（後面有空白），再把**下載的腳本檔案**拖進終端機，確認是該檔案的完整路徑後按 Enter。只有你輸入 `yes`，腳本才可繼續。

Windows：應由代理交付適用的 PowerShell 或其他對應腳本與執行方式。不要為了跑腳本全域降低執行原則、提權，或直接套用 macOS 的刪除指令。本倉庫沒有實測 Windows 清理流程。

若腳本顯示「略過」，先看原因。檔案有新變動、程序還在用、工具缺失或查核失敗時，正確做法是保留，必要時重新掃描；不是加 `--force`。

## 下一次再量

保留 `sizes.csv` 與代理交付的重新執行方法。可以對同一個代理說：

> 請沿用上次的唯讀掃描規則重新產生報告，先讀既有 sizes.csv，再追加這一輪結果，標出變大的項目。不要執行清理，也不要擴大掃描範圍。

不要把示範頁當成重新掃描功能；它沒有存取你的磁碟。也不要用舊報告的下載腳本處理已經大幅變動的檔案樹。

## 常見問題

### 頁面空白，或只有標題沒有數字

確認開的是 **`index.html`**，不是 `template.html`、`.html.in` 或 GitHub 上的 HTML 原始碼頁。代理必須交付已填入資料的完整頁面，並實際驗證地圖、清單與下載功能。

如果開對檔案仍空白，請代理查驗該頁面的 JavaScript 錯誤與資料是否載入；不要因此擴大磁碟權限。

### AI 說清理成功，但我沒有執行任何腳本

這不符合本流程。代理只能完成掃描、建頁與下載功能；沒有你執行腳本的實際證據，就不能宣稱已清理。

### 看到很多「僅供查看」，是不是壞了

不一定。用途不明、仍被使用、含記憶或作品、不能限定刪除範圍時，就應停用清理。模型、Docker 和資料庫不應因為容量大就直接刪掉。

### 沒有顯示 Claude／Codex 的全部紀錄

它們可能放在外接磁碟、自訂位置或符號連結後面；這些位置依本提示詞可能被跳過。不能為了「顯示完整」而偷偷越過原本的掃描範圍。

### 可以直接把我的報告分享出去嗎

不建議。檔案內容沒有被讀取，也仍可能暴露帳號、路徑、客戶或專案名稱。分享本倉庫即可；需要示範時使用 [`examples/demo.html`](../examples/demo.html) 的虛構資料。
